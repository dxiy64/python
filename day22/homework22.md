## 需求

| # | 功能 | 具体要求 |
|---|---|---|
| 1 | 按分类筛选 | 输入分类名，只打印该分类的流水；没有就提示"该分类没有账" |
| 2 | 按日期筛选 | 输入日期（如 `2026-09-23`），只打印当天的流水（时间字符串前 10 位比对） |
| 3 | 月度报表 | 输入月份（如 `2026-09`），打印当月**分类合计 + 总笔数 + 总支出**（都 `round(..., 2)`） |
| 4 | 导出 CSV | 把全部记录导出到 `day22/out/账单.csv`：`utf-8-sig` + `newline=""`，表头 `时间,金额,分类,备注` |
| 5 | 菜单 | 昨天分支不动，新功能加 2~3 个分支（筛选可并成 1 个分支里再问），`q` 退出 |

## 自查清单（每做完一段打勾）

- [ ] `t[:7]` 取年月、`t[:10]` 取日期 —— 时间格式固定才能这样切
- [ ] 筛选返回的照样是**列表**，后面 show / 求和 / 导出都能直接吃
- [ ] 月度报表 = 筛选（第 2 节零件）+ 分类求和（Day21 零件）拼起来
- [ ] CSV 三件套：`open(utf-8-sig + newline="")` → `writeheader()` → `writerows()`
- [ ] `DictWriter` 只认 `fieldnames` 里的键 —— 记录里多一个键就报错
- [ ] 导出前 `out/` 目录要存在（`mkdir(parents=True, exist_ok=True)`，复习 Day17）
- [ ] `out/` 只放**产出**：CSV 进版本库会越长越大，按惯例加进 `.gitignore`
