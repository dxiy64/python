## 三、最容易忘的 6 个"踩过的坑"（自测用）

1. **文件不存在时 `load()` 要返回什么类型？** → 跟容器类型一致（字典就返回 `{}`）
2. **工具箱里能不能写 `print` / `input` / 删文件？** → 不能，全进闸门
3. **`json.dump` 的中文乱码怎么办？** → `ensure_ascii=False`
4. **csv 在 Windows 上为什么要 `newline=""`？** → 不加会多出空行；编码要 `utf-8-sig`
5. **`for i in range(len(x))` 里读 `x[i+1]` 有什么问题？** → 最后一步必然越界
6. **`re.match` 和 `re.fullmatch` 的区别？** → `match` 只看开头，校验整串必须 `fullmatch`

```

     → ④还不行就 breakpoint() 进去看 → ⑤最后才问我（带上代码 + 完整报错）
```
