## 需求

一个能在终端里用的记账本：记一笔、看流水、统计花销、关掉不丢数据。

### 功能表（必做）

| # | 功能 | 具体要求 |
|---|---|---|
| 1 | 菜单 | `while True` + `input().strip()`，选 `q` 退出，非法输入提示后重来 |
| 2 | 记一笔 | 输入**金额**（必须是 >0 的数字，最多 2 位小数）+ **分类** + **备注**，自动带时间 `f"{now:%Y-%m-%d %H:%M}"`；金额不合法 → 提示并**重新问金额**，不许崩 |
| 3 | 看流水 | 逐行打印：`时间 金额 分类 备注`；空账本要有"还没有账"提示 |
| 4 | 统计 | 按分类合计金额 + 总支出（都 `round(..., 2)`）；`Counter` 只能数**笔数**，求和要自己累加 |
| 5 | 存档读档 | JSON，**列表套字典**（`[{金额, 分类, 备注, 时间}, …]`），`ensure_ascii=False`；文件不存在返回 **`[]`**（跟列表容器对上，不是 `{}`）；每次记账后 `save` |
| 6 | 结构 | 路径用 `pathlib`，`HERE` / `LEDGER` 常量**只定义一次**；`if __name__ == "__main__":` 闸门里只放动作 |

### 加分（选做，做不完不扣分）

- 按分类筛选流水（只看"午饭"花了多少）
- 只看某一天的流水（用时间字符串的前 10 位比对）
- 导出 CSV（`utf-8-sig` + `newline=""`，复习 Day17）

## 自查清单（每做完一段打勾）

- [ ] `0.1 + 0.2 == 0.3` 是 `False` —— 所以金额显示/存档前要 `round(..., 2)`
- [ ] `Counter` 是**数个数**的，分类求和必须自己 `get` + 累加
- [ ] `load()` 文件不存在返回 `[]`，返回 `{}` 会把整个程序带崩（列表 vs 字典）
- [ ] `save()` 用 `"w"` 是清空重写 —— 必须每次传**整本**数据
- [ ] `float("abc")` 抛 `ValueError` —— 用 `except` 接住，提示后 `continue` 重问
- [ ] 每个 `input()` 后面都跟 `.strip()`（一个隐形空格就能让统计漏一笔）
- [ ] `def` 必须定义在**第一次调用之前**
- [ ] 空列表是假值 → `if not rows:` 打印"还没有账"
- [ ] 闸门里只放动作（`main()`），工具箱顶层只放 `import` / 常量 / `def`
- [ ] 路径用 `Path(__file__).parent`，不用 `os.path`
